# 👺 도깨비 포커

밤 도깨비 장터에서 포커 족보로 점수를 내고, 부적을 모아 요괴를 물리치는 **싱글 덱빌딩 로그라이크**입니다. 브라우저만 있으면 PC와 휴대폰에서 바로 할 수 있어요.

**플레이:** https://leeseungje.github.io/dokkaebi-poker/

## 규칙

- 8구역 × 3판(첫 손님 → 큰손님 → 요괴). 목표 점수를 넘기면 판을 깨요.
- 손패 8장 중 1~5장을 내면 **점수 = 끗 × 배**. 판마다 내기 4번, 버리기 3번.
- 판을 깨면 냥(남은 내기·이자 포함)을 받아 **도깨비 장터**에서 부적·소모품을 사요. 물건마다 한 번 **흥정**할 수 있어요.
- **부적**(최대 5장)은 왼쪽부터 차례로 효과를 내요. 순서가 점수를 바꿔요.
- **소모품**: 족보 비급(족보 단계 올리기), 도깨비 방망이 19종(문양 바꾸기 최대 3장·복제·태우기·카드 추가·둔갑술·특수 카드 만들기), 도장 4종
- **보따리**: 카드·큰 카드·방망이·비급·부적·도장 보따리. 열어서 카드를 덱에 넣거나 덱 카드에 바로 써요.
- **특수 카드**: 복(+30끗)·불(+4배)·금(+3냥)·옥(×2배, 가끔 깨짐)·돌(+50끗, 숫자·무늬 없음)·도깨비(모든 무늬)·행운(+20배/+20냥 확률)·쇠(손에 있으면 ×1.5배)
- **도장**: 붉은(한 번 더 계산)·금(+3냥)·푸른(비급)·보라(버리면 방망이)
- **부적 40종**
- **요괴**: 무늬 봉인, 버리기 금지, 같은 족보 0점 같은 규칙으로 방해해요. 상점에서 미리 확인할 수 있어요.

## 소리

음원 파일 없이 Web Audio로 합성합니다. 국악 오음계 위에서 가야금 뜯는 소리, 북(배), 징(×배), 엽전, 목탁 소리를 내고, 배경 음악은 느린 장단 위로 가락이 즉흥으로 흘러요. 효과음과 음악 볼륨은 ⚙ 설정에서 따로 조절해요.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 족보·점수·런 진행 테스트
npm run sim 200  # 자동 플레이어로 밸런스 확인
npm run build
```

```
src/core/   게임 규칙 (화면과 분리된 순수 로직)
  hands.ts       족보 판정·기본 끗/배
  scoring.ts     점수 계산 (연출용 단계 기록)
  charms.ts      부적
  bosses.ts      요괴
  consumables.ts 비급·방망이
  run.ts         구역·판·상점 진행, 저장/불러오기
  bot.ts         자동 플레이어 (시뮬레이션용)
src/ui/
  app.ts     화면·연출
  audio.ts   소리 합성
```

배포: `npm run deploy` (테스트 → 빌드 → gh-pages 브랜치에 올림)
